Я могу выполнить следующие команды:
1. /listSpectra для вывода спектров индексированных в Базе данных, возвращат список в виде:
```
  id   имя   начало измерений   окончание измерений   статус
  1    1F220120 2020-01-22 10:00:00 2020-01-24 12:00:00   архивный
  2    2F121225 2025-12-12 08:00:00         -            измеряется
```
2. /getSpectrumInfo  для получения полной информации об измерении, результат выводится в виде:
   * id спетра : 1
   * имя спектра : *1F030405.spc*
   * канал: 1
   * дата начала измерения : `2005-04-03 10:00:00`
   * первый сохраненный файл : `2005-04-03 12:00:00`
   * дата окончания измерения : `2005-04-08 10:00:00`
   * статус : архивный
   * список файлов:
     - 1. `1F030405-2005-04-03_12-00-00.spc`
     - 2. `1F030405-2005-04-03_14-00-00.spc`
     - ....
     - 50. `1F030405-2005-04-08_12-00-00.spc`
3. /getSpectrumFiles id для получения файлов спектра по идентификатору
4. /checkState возвращает результат проверки текущего состояния спектрометра и компьютера, управляющего им.
